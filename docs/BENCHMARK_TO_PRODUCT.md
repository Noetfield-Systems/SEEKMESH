## Real delivered product, NOT mock
- Anonymous visitor: read actual indexed resources, search and click out to origin.
- Member: register pseudonymous handle + password (12+ characters) and gain 25 XP / 5 off-chain credits.
- Repeat usage: claim 4 XP / 2 credits once per UTC day; orientation primer: 20 XP / 5 credits once.
- Builder: submit useful original resource; queue exists and acceptance must be recorded by moderator.
- Approved builder: earn 40 XP / 20 credits and become eligible to spend 20 credits for seven days of clearly-labeled spotlight exposure of OWN approved source.
- Qualified invitation: inviter earns 15 XP / 5 credits only after the newly referred member contributes an approved original resource; no farming signups.
- Public rankings: actual database totals, zero is rendered as zero rather than fabricated metrics.
- Sponsors: expression-of-interest intake saved to production database; no checkout connected.
- Account: pseudonymous password login, 30-day random bearer token sessions, off-chain entries with unique idempotency keys.
- Token: **SEEK not issued.** MESH Credits/XP are internal non-transferable application units, not currency, rights to token distributions or USDC claims.

## Value equation (not marketing projections)
Contributors seek reputation + first-party visibility and learning; builders seek discovery and source-linked profile; paid customers seek relevant category visibility or machine-readable discovery data; agents need structured sources. The business is positive-margin only when collected sponsorship / data revenue minus content, operation and incentives is positive.

## Minimum viable commercial offer
**Founding Ecosystem Visibility Pack** — proposed C$49–99 once, editorial consideration (no guaranteed acceptance), a source-linked project profile and 7-day clearly marked spotlight when accepted. If a project is ineligible, decline and refund rather than selling endorsement. Live checkout not activated in this revision. Do not advertise proof of reach without analytics. Later product: subscription for premium discovery / agent-ready API, not generic 'get listed' fees.

## Four commercialization milestones
1. Measure actual return visits and search→source clicks (not yet instrumented).
2. Acquire 10 real open-source tool projects, 10 agents/builders, 3 category editors.
3. Sell the first fixed-scope sponsorship with collected payment and verified fulfillment.
4. Once paid discovery/API demand exists, test fee-backed contributor rewards; no speculative emission assumptions.

## Threats from the benchmark
- Layer3/Zealy games with no useful inventory decay fast.
- Kaito-style paid posting on X was disrupted by platform policy in 2026; avoid rewarding bulk posting and bot clicks.
- Presearch node payouts require an earning source to prevent permanent emission bleed.
- Coinbase Agentic.Market means x402 service aggregation is not an uncontested wedge.

## Next product releases (in order)
1. Add source-level evidence score, verified recrawl time and on-site engagement event instrumentation.
2. Add wallet sign-in via verifiable signed challenge, without pretending an unverified address is an identity.
3. Enable partner-owned projects with opt-in ownership verification and transparent sponsored placements.
4. Wire merchant checkout and confirmed settlement → fulfillment receipt.
5. Add onchain attestation and optional token utility, only when backed by real usage and an explicit chain contract.
